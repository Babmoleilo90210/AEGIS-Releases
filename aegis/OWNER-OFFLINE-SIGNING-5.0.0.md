# Офлайн-подпись АЕГИС 5.0.0

Приватный release-signing key остаётся на компьютере владельца. Его нельзя передавать в чат, Work, GitHub, CI, Relay или новый сервер. Закреплённый публичный ключ приложения не изменён. Служебный ключ нового сервера и пользовательские identity не являются ключами выпуска.

Проверьте SHA256SUMS, sourceCommit/tree в BUILD-PROVENANCE-5.0.0.json, соответствие обоих клиентских JAR-наборов, отчёты и release gates. `productionReady=false` запрещает представлять комплект завершённым Stable. Подписывание метаданных для явно отдельного испытания не является разрешением активировать Stable.

## Команды на доверенной офлайн-машине владельца

Распакуйте исходники того же commit и каталог окончательных артефактов. Команды выполняются из каталога `aegis` исходников. Замените пример пути к ключу своим существующим локальным путём; ключ не копируется в папку релиза.

```sh
sha256sum -c /path/to/artifacts/SHA256SUMS
python3 tools/sign-release-manifest /path/to/artifacts/stable-5.0.0.UNSIGNED.json /secure/offline/release-private.pem --output /path/to/artifacts/stable-5.0.0.UNSIGNED.json.sig
python3 tools/verify-release-manifest /path/to/artifacts/stable-5.0.0.UNSIGNED.json /path/to/artifacts/stable-5.0.0.UNSIGNED.json.sig --assets /path/to/artifacts
```

Штатный sign helper проверяет, что приватный ключ соответствует сохранённому публичному ключу. Ввод пароля защищённого ключа обслуживает локальный OpenSSL. Эти команды в среде разработки с ключом владельца не выполнялись.

## Проверка manifest

У версии 5.0.0 должен быть ровно `tag=v5.0.0`; URL артефактов должны содержать `/releases/download/v5.0.0/`. Суффикс beta в теге при версии без beta недопустим. Отдельный beta/test manifest использует канал beta и те же окончательные байты артефактов; производственный Stable feed в испытаниях не меняется. Совместимость канала, схемы, версии и URL проверяется текущим и замороженными историческими Java-парсерами.

Если изменён любой бинарник, документация release notes или инвентарь, пересчитайте SHA256SUMS и создайте новый unsigned manifest. Старую подпись нельзя переносить на изменённые байты. Manifest исключён из собственного инвентаря SHA256SUMS, поскольку подписывает этот инвентарь; это устраняет рекурсивный цикл хешей.

После фактической приёмки владелец отдельно разрешает GitHub Release и замену `updates/stable.json`/`.sig`. Копировать неподписанный файл в feed нельзя. Будущие GitHub URL в подготовленном manifest не означают, что публикация уже выполнена.
