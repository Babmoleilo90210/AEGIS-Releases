# АЕГИС 6.0.0 — «Экосистема»

Основная инструкция: **[README-6.0.0.md](README-6.0.0.md)**.

Это проверяемый кандидат существующего Java/JavaFX-приложения. Готовность Stable определяется обязательными испытаниями, а не названием файла или успешной компиляцией. Итоговые sourceCommit, SHA-256 и фактические результаты находятся в provenance и FINAL-VERIFICATION комплекта.

- Windows: [README-WINDOWS.md](README-WINDOWS.md).
- CachyOS: [README-CACHYOS.md](README-CACHYOS.md).
- Debian: [deployment/debian600/README.md](deployment/debian600/README.md).
- Android и подпись APK: [android/README.md](android/README.md).
- Восстановление: [MIGRATION-5.0.0-TO-6.0.0.md](MIGRATION-5.0.0-TO-6.0.0.md).
- Сборка: [BUILD-6.0.0.md](BUILD-6.0.0.md).

Ключ аккаунта и личный архив принадлежат отдельной Почте. Core хранит другой ключ устройства. Приватный release key и Android signing key остаются у владельца; production не подписывается в среде разработки.
