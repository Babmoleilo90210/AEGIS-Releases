# АЕГИС 5.0.0 — Организации, Новости, Библиотека и Безопасность

АЕГИС — настольное приложение на Java 21/JavaFX с защищённой перепиской, отдельным зашифрованным архивом, браузером «Взор» и голосовой связью «Глас».

Версия 5.0.0 подготовлена на основе точного исходного commit 2.5.0 `699a3260fa456a40d4d16d3b711c957b088f9ab3`. Новые организации, новости, мероприятия и общая библиотека используют отдельный сервер полномочий. Почтовый Relay и формат существующих писем не заменяются.

## Возможности

- Три блока навигации, шесть категорий настроек, контурные значки и сохранение шестнадцати пресетов.
- Автоматическая подготовка компонентов Взора через Polkit/UAC, проверка официальной подписи Tor Browser и явная диагностика ошибок изоляции.
- Отдельные разрешения входящих/исходящих вызовов Гласа, запреты для контактов и короткие серверные организационные разрешения.
- Заявки на организации с одобрением администрации, роли с наследованием, независимые уровни допуска и подтверждения личности/должности.
- Новости, модерация, опросы и мероприятия; город выбирается вручную.
- Общая библиотека с графом, деревом, документами, историей редакций, Markdown и визуальным редактированием.
- Центральный ИИ-редактор и отдельные рабочие узлы, проверка источников, бюджеты и редакционная очередь.

## Начало работы

Инструкции установки находятся в README-WINDOWS.md и README-CACHYOS.md. Запускайте приложение обычным пользователем. Java, Tor и голосовые библиотеки включены в клиентский пакет.

Существующие письма, ключи и личный архив остаются локальными. Перед первым открытием новой версией создаётся проверяемый снимок профиля. Не удаляйте старую установку и резервные копии до проверки обновления.

Для общих функций владелец инфраструктуры отдельно разворачивает сервер из серверного пакета, выполняет защищённую первоначальную настройку двух администраторов и сообщает пользователям onion-адрес и отпечаток открытого ключа. Их нужно сверить по доверенному каналу и указать в «Настройки → Сеть, Tor и обновления». Отсутствующий сервер не подменяется локальными организациями или выдуманными публикациями. COMMUNITY-SERVER-5.0.0.md описывает процедуру; SERVER-DEPLOYMENT-PROPOSAL-5.0.0-RU.md отделяет её от production Relay.

Для ИИ-редактора администраторы задают разрешённые источники и модель. Поддерживаются локальный Ollama и HTTPS API совместимого формата. Ключи внешнего API хранятся у оператора, не в клиенте. При отсутствии модели система не выдаёт алгоритмическую имитацию за проверку нейросетью.

## Статус комплекта

Целевая версия — Stable 5.0.0. До обязательной нативной, сетевой и подписанной updater-приёмки комплект является кандидатом для владельца; `productionReady=false`. Точный перечень проверок и ограничений приведён в TEST-REPORT-5.0.0.md и RELEASE-GATES-5.0.0.json. Результаты прежней версии не являются приёмкой этих новых бинарников.

Windows Home не поддерживается для Взора. Доступ к общим серверным материалам не является сквозным шифрованием личного архива. Захват конечного устройства остаётся границей защиты. Подробности приведены в SECURITY-AUDIT-5.0.0-RU.md, VZOR-5.0.0.md и GLAS-5.0.0.md.

Ни приватный ключ подписи владельца, ни пользовательские данные в комплект не включаются. Подпись и публикация выполняются владельцем отдельно после приёмки. Production Stable feed автоматически не меняется.
