Предыдущий ограниченный прогон выявил несовпадение входов теста миграции: исходник теста 5.0 использовал Appearance из опубликованного JAR 2.5.0. Это не результат проверки новой реализации Appearance. Исправленный прогон компилирует текущий Appearance.java вместе с пакетом safeweb. Один реальный тест UNIX-сокета прерывается по предпосылке из-за запрета AF_UNIX в среде.
