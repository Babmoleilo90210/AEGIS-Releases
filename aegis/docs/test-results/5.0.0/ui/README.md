# Финальная автоматическая проверка JavaFX 5.0.0

Проверены замороженные production JAR после исправления серверной пагинации. Smoke-классы компилируются отдельно: ни один production-класс не загружен из каталога smoke-классов. Это подтверждается CodeSource, SHA-256 класса и SHA-256 JAR в каждом RESULTS.json. Старые модули АЕГИС 2.5.0 исключены из classpath; используются только закреплённые сторонние зависимости.

| Проверка | Результат | Реальные PNG | Область |
|---|---|---:|---|
| ArchiveMenu500Smoke | PASS_HEADLESS | 8 | Настоящий временный зашифрованный архив; 24 измерения Label/текстовых границ трёх меню, 2 темы × 4 масштаба |
| Interface500Smoke | PASS_HEADLESS | 61 | 11 действий навигации в 3 блоках, 6 категорий настроек ниже меню, все 16 пресетов, 800×600 и масштабы 100/125/150/200%, ещё 36 фактических layout-сочетаний размеров |
| Community500FlowSmoke | PASS_LOCAL_INTEGRATION | 6 | Реальные production ContentService/OrganizationService/AdminService/AgentService и SQLite через внутрипроцессный адаптер, production StrictJson/CommunityJson |
| AgentSourcesPagingProbe | PASS_LOCAL_INTEROP | 0 | 1000 реальных строк AgentService → 10 страниц → production StrictJson и CommunityJson; наибольшая страница 26356 байт |

Всего 75 снимков настоящего JavaFX; сгенерированные изображения не используются. В отдельном state-тесте применены строго декодируемые синтетические страницы: достигнутый предел 500 узлов, E:-продолжение limit=1/dedup, затем 2016 связей с ограничением представления 2000 и постоянным предупреждением. Эти синтетические входы подтверждают управление состоянием UI; они не подтверждают авторизацию сервера. Серверный dense-graph тест учитывается отдельно.

Интеграционный сценарий действительно сохраняет новость, создаёт мероприятие и открывает его по дню, меняет календарный месяц с явными startsFrom/startsTo, создаёт и изменяет документ библиотеки, подаёт заявку организации и проверяет отсутствие неодобренной организации в каталоге. Административный раздел открывается по действующей серверной идентичности. CityPicker загружает все 1000 городов через последовательные реальные страницы и выбирает последний; AdminView собирает 1000 источников без повторов через кнопку «Ещё». Начальные каталоги подготовлены прямым SQL в отдельной тестовой БД; чтение, авторизация, пагинация, сериализация, decoder и UI настоящие. Публикация, пароль/OTP действия, сеть и модель не имитируются успешными: они не входят в этот сценарий.

Нативная приёмка Windows 11/CachyOS KDE Wayland/X11, Tor/Relay/TLS, микрофон, два физических устройства и updater E2E: **NOT_RUN в этих проверках**. Monocle не заменяет эти испытания; UI результаты не повышают productionReady.

INPUTS.json содержит входные SHA-256. *-command.json и *.log сохраняют точные команды и вывод. sources/ содержит использованные smoke/helper исходники; их SHA совпадают с INPUTS.json. run-frozen-smokes.py воспроизводит процедуру в данном рабочем окружении и отказывается перезаписывать существующую попытку. Production JAR не дублируются в этом каталоге: сравнивайте зафиксированные хеши с JAR релизного пакета.

В paging/ сохранены исходник и вывод дополнительного production interop probe. BEFORE-FIX.log — историческое воспроизведение переполнения JSON node budget (1000 источников одним ответом на старом server JAR 533075cce5c2eb72369e58bbae9fa4776d4c06f0ac37da92f06f2d6415cef737). PASS.log — итоговая пагинация на зафиксированном server JAR 8013130dd4f8fa14682a14588cb17f1c2fc7dc240fb68fa97a388f3672b1bfaa. Предварительные геометрические попытки также выявили вертикальное обрезание меню архива, сжатие календаря и перенос двузначных дат; исправления проверены финальным повтором. Старые успешные прогоны до последнего hardening/pagination не подменяют результаты данного каталога.
