# Локальная нагрузочная проверка community-server 5.0.0

Фактически выполнен один ограниченный запуск `tools/benchmark-community500.py` с отдельными синтетическими БД на 100, 1000 и 3000 материалов. Для каждого набора 25% материалов разрешены только автору, 75% доступны читателю без ролей; до 100 утверждённых связей включают закрытые вершины. Все создания, публикации, связи и чтения выполняются production ContentService/AccessControl и настоящей SQLite. Только учётные записи/исходная роль созданы SQL-фикстурой.

Конфигурация: Linux 6.18.44 amd64, 8 доступных CPU, Eclipse Adoptium Java 21.0.12.1, heap 64–384 МиБ. Это один контейнерный хост, без сети, Tor, JavaFX, нативных Windows/CachyOS или физических аудиоустройств.

| Материалы | GET доступный p95, мс | GET закрытый p95, мс | Первая страница p95, мс | Поиск закрытого canary p95, мс | Граф первой страницы p95, мс | Полный обход графа p95, мс |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 100 | 0,362 | 0,427 | 7,876 | 14,125 | 7,379 | 9,358 |
| 1000 | 0,289 | 0,221 | 18,260 | 68,133 | 22,004 | 99,854 |
| 3000 | 1,464 | 1,861 | 42,213 | 208,788 | 33,189 | 513,554 |

GET измерен по 30 запросам, первая страница/первая страница графа — по 20, поиск canary — по 10. Полный обход измерен всего три раза, поэтому его p95 является максимумом этих трёх измерений и не годится как общий SLO. Соответственно обработано 75/750/2250 доступных узлов за 1/8/23 страницы; каждый найден ровно один раз.

Все встроенные утверждения выполнены: закрытый GET возвращает NOT_FOUND, закрытый canary не находится поиском, граф не раскрывает недоступные вершины и концы связей, все публичные узлы выдаются ровно один раз, административная хеш-цепочка целостна. RAM, RSS, thread CPU и распределения всех измерений сохранены в RESULTS.json. Heap после набора 3000 составил 31 214 272 байта; это моментальное значение, не заявленный пик.

Измерения включают текущую серверную проверку прав. Они не включают Tor-задержку, HTTP-сериализацию, файловые медиа, пользователей разных сетей или длительную многопользовательскую нагрузку. Это не полная нагрузочная приёмка Stable.

Повторение из корня Java-проекта:

```sh
python3 tools/benchmark-community500.py --jdk /путь/к/проверенному/jdk-21 --deps /путь/к/проверенным/jar --output docs/test-results/5.0.0/load
```

Требуемые зависимости: sqlite-jdbc-3.53.4.0.jar, slf4j-api-2.0.17.jar, slf4j-nop-2.0.17.jar. Скрипт сохраняет SHA-256 источников, компилятора и зависимостей, реальную конфигурацию JVM, время и журнал; временные БД удаляются после завершения. Предыдущий запуск до ограничения payload метаданными сохранён отдельно в load-before-metadata, с собственными исходными хешами.
