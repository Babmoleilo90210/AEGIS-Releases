# Проверка внешних Maven-зависимостей 5.0.0

Инструмент `tools/audit-dependencies500.py` получил реальные ответы официального OSV API для 34 точных Maven-координат. Проверены байты предоставленных JAR, Maven metadata или явное соответствие известному имени, Gradle runtime pins и lockfiles. Результат — `QUERIES_COMPLETE`: все точные запросы завершены, совпадений с известными OSV advisory для этих версий не найдено. Это не доказательство отсутствия неизвестных уязвимостей и не нативная приёмка.

33 исходных запроса сохранены в `BASELINE-QUERY-SNAPSHOT.json`. В нём обнаружено действительное несовпадение: Gradle требует commons-logging 1.4.0, а пакет 2.5.0 содержит 1.3.5. После предоставления проверенного Gradle JAR 1.4.0 выполнен дополнительный реальный запрос и сохранены его байты/SHA-256. Ранее полученные успешные ответы переиспользованы с проверкой хэшей, исходной датой и SHA-256 снимка. Скан включает обе версии logging для сравнения с базой; финальный пакет должен содержать только закреплённую 1.4.0. Инвентаризацию конечного staging следует выполнить повторно с тем же `--reuse-snapshot`, не повторяя неизменившиеся сетевые запросы.

Пример команды для конечных runtime-зависимостей:

```sh
python3 tools/audit-dependencies500.py \
  --jars /absolute/path/to/final-runtime-deps \
  --out /absolute/path/to/audit-output \
  --reuse-snapshot docs/test-results/5.0.0-dependencies/DEPENDENCY-AUDIT-5.0.0.json
```

JUnit/Monocle и собственные JAR приложения исключены из продуктового Maven-аудита. Нативные Opus/SpeexDSP, Tor, Tor Browser, JVM и системные компоненты перечислены как отдельная область upstream advisory/native testing; отсутствие Maven-совпадений их не проверяет. Для этой общей области `productionReady=false` сохраняется до обязательной приёмки.

`tool-tests.log` содержит четыре успешных теста самого инструмента: извлечение координат/хэша, classifier и исключения тестовых библиотек, честный NOT_RUN при сбое сети, блокировка синтетического HIGH. Эти синтетические записи существуют только во временных тестовых каталогах и не являются реальными найденными уязвимостями продукта.

Официальная документация API: https://google.github.io/osv.dev/post-v1-query/
