# Доказательства разработки АЕГИС 5.0.0

Каталог содержит фактически выполненные отдельные прогоны, их команды, исходные SHA, результаты, реальные JavaFX PNG и ограничения среды. Это история разработки до фиксации итогового commit, а не автоматическое подтверждение Stable.

Авторитетный общий прогон после фиксации исходников находится в отдельном релизном `AEGIS-5.0.0-final-test-evidence.zip`: source receipt до тестов, проверка неизменности всего Git tree, свежие Gradle XML, точный inventory и матрица. Его числа не складываются с повторными целевыми прогонами этого каталога. Inventory с `sourceCommit=null` является снимком до freeze.

`access/regression-role-escalation-before-fix/` сохраняет две настоящие неуспешные проверки уязвимой реализации до исправления. Они отдельно помечены и не являются открытым дефектом исправленного кандидата. Аналогично первоначальные ошибки тестовых harness сохраняются рядом с повторными успешными прогонами, когда это помогает воспроизведению.

`ui/` содержит снимки приложения JavaFX/Monocle и проверку точных production JAR/CodeSource. Это реальные отрисованные элементы приложения, но не нативная приёмка Windows 11 или CachyOS KDE. Контролируемые тестовые аккаунты, источники, модели и SOCKS-стенды обозначены в отчётах; они не выдаются за production Tor, физические устройства или действующий ИИ-сервис.

Исходные shared-чаты, полные полученные веб-страницы, пользовательские vault/архивы, приватные ключи, API-токены, HTTP cookie/authorization и окружение в этот каталог не включены. Для внешних источников сохраняются ссылки, дата, SHA и краткие выводы; публичные подписи официальных Tor-архивов сохранены отдельно.

`productionReady=false`, пока не завершены обязательные внешние проверки точных релизных артефактов и приёмка владельца. Старое сообщение о тестах 2.5.0 не закрывает новые сценарии 5.0.0.
