# Целевой прогон «Гласа» и миграции 5.0.0

85/85 PASS, 0 SKIP, 0 FAIL. Скомпилированы текущие классы voice и Appearance.java с Java 21 поверх точных зависимостей и прочих классов 2.5.0. Их classes идут первыми в classpath. Это целевой прогон подсистем, а не общий билд всех новых модулей 5.0.0.

Реальные JSSE TLS-сокеты используют явно заданный loopback тестовый Connector. MediaFactory/аудиоустройства управляемые тестовые; отдельные codec-тесты загружают настоящие запечатанные комплектные Opus/SpeexDSP. Микрофон пользователя и внешняя сеть не используются. Тесты хранилища создают настоящие зашифрованные vault и независимый архив в одноразовых TempDir. Нативная приёмка Windows/CachyOS и Tor не заявляется.

`RESULTS.json` содержит SHA-256 всех исходников и фактических JAR/native входов. `reproduce-targeted.py` воспроизводит команды в структуре восстановленного рабочего каталога; пути к доверенным входам при переносе нужно заменить. Полная сборка 5.0.0 выполняется отдельно после объединения модулей.

В журнале остаются предупреждения Speex об искусственно ускоренных playback fixtures и JUnit об удалении тестового symlink. Они не являются измерением акустического качества или ошибкой проверки.
