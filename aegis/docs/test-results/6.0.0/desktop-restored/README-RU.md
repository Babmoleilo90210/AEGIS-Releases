# Восстановленные проверки настольной Почты 6.0.0

Фактически выполнено на Linux-контейнере с JDK 21.0.12.1+1 и Monocle. Нативная приёмка Windows 11, CachyOS Wayland/X11 и запуск песочницы: **NOT_RUN**. Настоящий Tor и удалённое завершение восстановления устройства здесь не испытывались.

- **15/15 JUnit — PASS:** 8 проверок файловых границ, 5 проверок реальной зашифрованной идентичности восстановления и 2 проверки неразрушающей миграции.
- **21 проверка страницы архива — PASS_HEADLESS:** небезопасный сохранённый путь не открывается, пароль не запрашивается, другой архив автоматически не создаётся, старые настройки не перезаписываются. Повреждённый или относительный путь также блокируется. Четыре реальные PNG: две темы × масштаб 100/200% при 800×600.
- **9 проверок формы восстановления — PASS_HEADLESS:** реальные элементы JavaFX, открытие частной копии настоящего тестового зашифрованного LocalStore, исходная идентичность не изменяется, пароль очищается, согласие явно даётся и отзывается. Три реальные PNG. Начальное удалённое задание заменено явно обозначенной локальной типизированной фикстурой. Выдача удалённого допуска этой проверкой не доказывается.
- **16 локальных проверок DeviceRecovery — PASS:** фиксированная цель, приложение, подпись нового устройства, закреплённый публичный ключ, срок и точные поля запроса. Это не сетевой прогон.
- **Перенаправление управления администраторами — PASS_HEADLESS:** фактическая JavaFX-страница Core 6 вызывает предусмотренный callback Identity, не показывает старые кнопки и не отправляет старые Community-запросы выдачи/отзыва глобальных администраторов. Данные RPC в этой проверке являются фикстурой интерфейса; серверная авторизация проверяется отдельными тестами Identity.

Первый прогон дал 12/15 PASS и 3 FAIL: тест использовал старый SafeWebSessions.defaultRoot(), который зависит от тестового aegis.profile, вместо отдельного XDG-каталога автономного менеджера Взора. Пробный вызов подтвердил отклонение фактического каталога менеджера. Исправлены тестовые пути; производственная политика не ослаблялась. Исходный ошибочный результат сохранён как FIRST-EXECUTION.json/FIRST-test.log. Повтор и отдельный запуск воспроизводимого сценария прошли без изменения проверяемых исходников и входных файлов.

Команды воспроизведения после сборки Java-классов:

```bash
python3 packaging/tests/run-mail-boundary-smoke600.py \
  --jdk /absolute/path/to/jdk-21 \
  --dependencies /absolute/path/to/verified-maven-jars \
  --native-root /absolute/path/to/native-bundle \
  --output /absolute/path/to/new-empty-output
```

`--native-root` содержит подпапку `native/` с проверенными libsodium/Opus/Speex. В данном прогоне использованы бинарники из проверенного исходного пакета 5.0.0. Сценарий копирует с проверкой SHA-256 скомпилированные классы и ресурсы в отдельный каталог, затем проверяет неизменность входов. Вывод и XML JUnit сохранены. `EXECUTION.json` содержит точные хеши проверяемых исходников и скопированного байткода. Прогон выполнен по рабочему дереву, **не является доказательством единого окончательного релизного commit** и не устанавливает productionReady=true.
