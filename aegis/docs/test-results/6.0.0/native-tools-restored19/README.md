InRelease официального Ubuntu snapshot заново проверен gpgv с системным Ubuntu archive keyring. SHA и размеры Packages.xz сверены с подписанным InRelease. Все 14 выбранных package name/version/Filename/SHA/Size совпадают с неизменёнными закреплёнными значениями registry. Установки в систему и maintainer scripts не выполнялись.

Прежний pin дерева `46aa22...` не получился из точных официальных архивов и был отклонён. Старое mutable tree потеряно вместе со средой; причина его отличия неизвестна. Вместо принятия несовпадающего дерева проведена независимая реконструкция: обычный `dpkg-deb -x` и потоковое data-only чтение членов tar. Каждый из 4820 обычных файлов, 3335 symlinks и 142 каталогов сверён с SHA/target/mode официального архива. Два каталога после dpkg имели 0700 вместо объявленного 0755; применены именно официальные directory modes. Оба независимо извлечённых дерева после этого дают **ac336f4a59d9ae10461dec1af55327b979175bae24bc511ca9f988af3575c9c8**. Дополнительная проверка выявила не входящий в архивы временный `.lto1.xro8mI`, и tree guard снова отказал. Этот файл перемещён в диагностический quarantine вне build input, его размер/SHA сохранены; причина создания внешнего/временного файла не доказана. Позднее загрязнённый независимый scratch-каталог целиком удалён; текущий основной build input отдельно совпадает с полным manifest официальных архивов. Ни дополнительный файл, ни иной изменённый исполняемый компонент не принят. Результат второго дерева ac336f относится к моменту его создания и проверки manifestEquality, а не к позднему загрязнённому состоянию.
