# Показ уведомлений Core 6.0.0

Добавлены локальные параметры: звуковой сигнал, сообщение внутри текущего окна, скрытие заголовка в этом сообщении. По умолчанию звук выключен, сообщение включено и содержит только «Новое уведомление АЕГИС.». Явное отключение скрытия разрешает показать очищенный заголовок. Системных всплывающих окон и отдельного окна приложения нет.

Файл `core600/notification-preferences.json` содержит схему и три логических значения, ограничен 2048 байтами, сохраняется атомарно в приватном каталоге и включён в allowlist резервной копии. В нём нет заголовков, account ID и ключей. Неверный или неоднозначный файл сохраняется без перезаписи; до исправления действуют безопасные значения. Ограничивающие изменения применяются сразу, разрешающие — только после успешного сохранения.

Получение первой страницы формирует беззвучную исходную точку. Историческая пагинация не создаёт сообщения. Новое непрочитанное событие из успешно проверенной сервером страницы может вызвать сообщение и запрос системного звука. В памяти хранится не более 1024 идентификаторов; данные на диске не дублируются. Существующие серверные категории, ACL, пагинация и обновление раз в 15 секунд сохранены. Проверка работает в открытом центре уведомлений; она не обещает постоянную фоновую доставку всех событий при закрытой странице.

`close()/lock()` сразу запрещает показ и звук, инвалидирует отложенные ответы, очищает баннер и загруженные строки. Потеря доступа или ошибка обновления скрывает прежние сведения. Категории на сервере независимы от локальных параметров показа.

Выполнены 12 JUnit-проверок, включая повреждённый JSON, ссылки, атомарную запись, первоначальную тишину, старую пагинацию, ограниченную память, очистку текста, дедупликацию и закрытие. Свежий согласованный Gradle-прогон: 12/12 PASS, 0 пропусков; XML и SHA-256 прилагаются. Общий focused Core-прогон — 51/51 PASS, но это изменяемый development snapshot, не релизная приёмка.

В JavaFX Monocle выполнены настоящие signed Identity/Community HTTP и SQLite запросы через явно тестовый SOCKS-маршрутизатор. Публикация нового события показала нейтральный баннер; повторное обновление не повторило его. Проверены сохранение параметров, явное раскрытие заголовка, отключение баннера, запросы звука и поздний ответ после блокировки. При новом открытии ранее полученные события не озвучиваются. Три PNG — реальные снимки этого JavaFX-прогона.

Звуковой callback проверен счётчиком запросов; фактическое звучание системного динамика, Windows 11, CachyOS KDE Wayland/X11 и публичный Tor здесь **NOT_RUN**. Генерированных изображений нет. Эти результаты не дают оснований выставлять `productionReady=true`.
