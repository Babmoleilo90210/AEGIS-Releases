# Общий диалог: зависимая от ширины высота

После предыдущего прохода воспроизведён новый реальный дефект: 24 Label с переносом при 800×600/150% оставляли кнопки ОК/Отмена на y1158–1215 даже при v=1. DialogPane сообщал отсутствующий content bias, поэтому VBox оценивал высоту без фактической ширины и ScrollPane получал неверный диапазон.

Минимальная правка задаёт для DialogPane HORIZONTAL content bias. Новый `InWindowDialogs200Smoke` проверен без изменения: 8 сочетаний темы и масштаба, подписи кнопок, границы сцены и clipping ancestors, сохранность черновика, закрытие вложенных страниц и одно окно. Финальный source override PASS: на150% кнопки y510–567, на200% y480–556. Результаты до исправления сохранены UI-агентом отдельно; этот каталог содержит фактический исправленный прогон.

Основной JAR этим тестом не изменялся. Нативная приёмка Windows11/CachyOS — NOT_RUN. Root затем повторит на общем rebuilt JAR.
