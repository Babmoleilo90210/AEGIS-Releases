# АЕГИС 6.0.0 — «Экосистема»

Продолжение существующего Java/JavaFX АЕГИС 5.0.0. Это кандидат для проверки владельцем, а не подтверждённый Stable. Статус готовности вычисляется по реальным обязательным испытаниям. Недоступные проверки не считаются успешными.

## Что входит

Главный АЕГИС управляет ключом устройства, входом, сообществами, «Вестником», настройками, уведомлениями и запуском отдельных приложений. Почта одна открывает прежнюю почтовую идентичность, переписку, контакты и личный зашифрованный архив. Глас использует отдельный ключ приложения и существующий Tor/TLS/Opus транспорт. Взор запускает официальный Tor Browser отдельно. Библиотека имеет разные личный и защищённый профили Obsidian и отдельный серверный ACL-коннектор.

Поставки: Debian13 Server, Windows11 x64 Setup/Portable, CachyOS KDE AppImage, четыре Android13+ARM64 APK (АЕГИС/Core, Почта/Mail, Глас/Glas, Страж/Strazh). Файлы unsigned требуют подписи владельца. TEST APK подписаны только временным тестовым сертификатом. Они не являются production-подписью.

## Первый запуск

1. Проверьте SHA256SUMS, источник и provenance. Точные commit/tree и результаты общего прогона находятся в итоговых JSON рядом с файлами.
2. Разверните отдельный staging по `deployment/debian600/README.md`. Получите onion-адреса и открытые ключи сервисов у оператора по доверенному каналу; сверьте полные отпечатки.
3. Откройте АЕГИС и настройте Identity, затем серверы приложений. Не вводите почтовый пароль в Core: ключ устройства имеет свой пароль.
4. Привязка прежней почтовой идентичности и чувствительные подтверждения выполняются отдельным процессом Почты. Root/recovery private keys не копируются в Core или Глас.
5. Первоначальный Owner назначается операторской CLI с доказательством владения account key. Никнейм не даёт полномочий. См. `identity-server/OWNER-ADMINISTRATION-6.0.0.md` и `IDENTITY-ADMINISTRATION-6.0.0.md`.

При восстановлении устройства нужны зашифрованная копия почтовой идентичности и отдельный `.aer6`. Один recovery-файл не заменяет потерянный root key. Прежние поколения серверных сессий отзываются; чувствительные полномочия возвращаются после предусмотренного независимого подтверждения.

## Закрытие и независимые приложения

Блокировка очищает чувствительный UI и локальные сессии. Полный выход завершает Почту, Глас и защищённую Библиотеку. Личный Obsidian и Взор могут продолжать работу отдельно. Для установки/отката программы закройте их: runtime guard запрещает замену используемых файлов.

## Границы кандидата

Физические Windows11/CachyOS/Debian13/Android и два устройства в разных сетях требуют отдельной приёмки. Headless JavaFX, локальные HTTP/SOCKS и синтетический PCM её не заменяют. Android пока не повторяет весь настольный набор архива, P2P и потоковых вложений 500 МиБ; работа VPN/Doze/микрофона/FLAG_SECURE требует устройства. Закрытый Android Obsidian не запускается через небезопасный общий каталог.

Личный архив не передаётся общей Библиотеке или новостному ИИ. Существующий защищённый коннектор проверяет права каждого материала; отдельная модель Syncthing всего закрытого vault не используется. Плагины Obsidian не имеют собственной песочницы. Полностью заражённое конечное устройство находится за пределами гарантий.
