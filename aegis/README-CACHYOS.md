# АЕГИС 1.1.5 — CachyOS x86_64

Кандидат для приёмки. Проверка на настоящем KDE Wayland/X11 пока не выполнена. Не заменяйте единственный профиль без резервной копии.

Скачайте `AEGIS-1.1.5-CachyOS-x86_64.AppImage`. В Dolphin разрешите выполнение файла через его свойства и откройте. Эквивалент:

```sh
chmod +x AEGIS-1.1.5-CachyOS-x86_64.AppImage
./AEGIS-1.1.5-CachyOS-x86_64.AppImage
```

Java 21, Tor и Snowflake уже внутри. Без FUSE:

```sh
./AEGIS-1.1.5-CachyOS-x86_64.AppImage --appimage-extract-and-run
```

Дождитесь подключения, вставьте `.onion` сервера и нажмите «Подключиться». Создайте аккаунт или войдите. Для другого устройства восстановите свой зашифрованный identity backup; повторная регистрация вместо восстановления создаст другую identity. Обычные письма открываются после E2EE автоматически. Дополнительная защита и защищённый ответ требуют новых вручную заданных пароля письма и FF1 code.

Сохраняются прежние XDG пути профиля. Изменение оформления не теряет черновик; он остаётся только в памяти. Перед миграцией/updater сохраняет полный профиль ciphertext/settings, ключи, письма, TTL/receipts, аватары и Tor state. Экспорт identity не заменяет backup переписки.

Используется исключительно встроенный Tor с собственными `--defaults-torrc` и `-f`. `/etc/tor/torrc` и его `User` не читаются. SOCKS почты 127.0.0.1:19050, Control 19051, SOCKS обновлений 19052 и локальный P2P 19120 слушают loopback. Публичные входящие порты, sudo и системная служба для клиента не нужны. Tor unavailable означает offline; clearnet fallback отсутствует.

«Открыть без сети» показывает непосроченную локальную почту после разблокирования. Уведомления нейтральные; без системного tray на Wayland показываются внутри окна. Семидневное локальное разблокирование через Secret Service зависит от хранилища секретов KDE; без него остаётся пароль. Сетевой bearer Relay 0.2.0 живёт 12 часов или до перезапуска сервера.

Первый переход из 1.0.0 — проверенная замена AppImage: [MIGRATION-1.0-TO-1.1.md](MIGRATION-1.0-TO-1.1.md). В 1.1.5 updater использует Tor и обязательные Ed25519/SHA-256 проверки, установка требует согласия. Production подпись и публикация этого кандидата ещё не выполнены.
