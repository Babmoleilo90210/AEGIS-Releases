# АЕГИС 1.1.0 — кандидат

Пакет содержит Java 21, собственный Tor и необходимые библиотеки; глобальные Java/Tor не нужны. В native ОС пока не принят: смотрите TEST-REPORT-1.1.0.md. Production release ещё не опубликован; будущие GitHub ссылки v1.1.0 не являются уже доступными загрузками. Для первого перехода см. MIGRATION-1.0-TO-1.1.md.

# АЕГИС 1.0.0 для CachyOS

1. Скачайте **AEGIS-1.0.0-CachyOS-x86_64.AppImage**.
2. В свойствах файла откройте **Права доступа** и разрешите выполнение.
3. Откройте AppImage двойным щелчком.
4. Дождитесь подключения Tor, вставьте адрес `.onion`, выданный владельцем сервера, и нажмите **Подключиться**.
5. Создайте аккаунт или войдите по нику и паролю. Адрес сервера сохраняется.

Java и Tor уже внутри. Не нужно отдельно устанавливать Java или Tor Browser. Не запускайте клиент через sudo.

Подписывать файлы и выполнять команды перед запуском не требуется. Проверка обновлений по умолчанию выключена; она не блокирует вход и сообщения. Для ручного обновления скачайте новую AppImage; данные профиля сохраняются отдельно от файла приложения.

Если предпочитаете терминал, из папки загрузок:

```sh
chmod +x AEGIS-1.0.0-CachyOS-x86_64.AppImage
./AEGIS-1.0.0-CachyOS-x86_64.AppImage
```

На минимальной системе без FUSE доступен запуск `./AEGIS-1.0.0-CachyOS-x86_64.AppImage --appimage-extract-and-run`. Обычная desktop CachyOS должна иметь GTK3, fontconfig и XWayland для JavaFX.

Если Tor не может подключиться, приложение показывает ошибку и остаётся offline. Настраивать сервер, открывать входящие порты или менять firewall для обычного запуска не нужно.

Техническое описание находится в `docs/OPERATIONS-CACHYOS-1.0.0.md`. Реальная CachyOS/KDE в текущей Ubuntu-среде не проверена; подробный статус указан в отчёте.
