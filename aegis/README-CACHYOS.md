# АЕГИС 5.0.0 — CachyOS KDE x86_64

**Кандидат; productionReady=false.** Linux-компиляция и headless JavaFX выполнены на Ubuntu 24.04; они не заменяют CachyOS KDE Wayland и X11. Эти окружения проверяются отдельно.

Проверьте SHA256SUMS. Разрешите выполнение `AEGIS-5.0.0-CachyOS-x86_64.AppImage` и запустите его обычным пользователем. Java 21, Tor, libsodium, Opus и SpeexDSP входят в комплект. При отсутствии FUSE используйте штатный режим AppImage `--appimage-extract-and-run`. Сохраняйте исходный профиль и старый AppImage до окончания испытаний.

## Взор

Для изоляции используются системные bubblewrap, slirp4netns, Xephyr, user/network namespaces и локальный X-сокет. На Wayland нужен рабочий Xwayland для вложенного Xephyr; прямой доступ браузера к пользовательскому Wayland/X11 display не предоставляется.

Нажатие «Открыть Взор» запускает автоматическую проверку компонентов. На поддерживаемой CachyOS/Arch при необходимости АЕГИС предлагает системное подтверждение Polkit и выполняет только фиксированную установку разрешённых пакетов через системный pacman: `bubblewrap`, `slirp4netns`, `xorg-server-xephyr`, `xorg-xwayland`, `gtk3`, `dbus-glib`. Само приложение работает обычным пользователем и не получает пароль администратора. AUR, произвольные root-команды, отключение подписей пакетов и автоматическое полное обновление ОС не используются. После установки Xwayland может понадобиться повторный вход в KDE. Подробности и границы — в VZOR-5.0.0.md.

Менеджер пакетов использует сетевую политику ОС и может обращаться к официальным репозиториям напрямую; эта подготовка не объявляется анонимной загрузкой через Tor. При отказе Polkit, запрете namespaces, отсутствии компонентов или ошибке песочницы Взор показывает причину и блокирует запуск. Изоляция не отключается; обычный запуск браузера вместо неё не выполняется. Нативная установка и запуск на CachyOS требуют отдельной приёмки.

Нажмите «Взор» → «Открыть Взор». Официальный пакет и его `.asc` загружаются через Tor, проверяются до распаковки и публикуются атомарно. Обнаруженная установка в XDG-каталогах/домашнем каталоге не является доказательством подлинности и не копируется вместе с cookies/паролями. При недоказуемом происхождении получается свежая официальная копия.

Обычная и временная сессии разделены. Временная удаляется после подтверждённого завершения; физическое стирание SSD не гарантируется. Загрузки находятся в отдельном каталоге и не исполняются автоматически. Импорт в архив требует явного действия и существующей разблокировки.

## Глас

Проверьте доступ Java Sound к выбранным устройствам. Нативная работа с PipeWire/PulseAudio/ALSA, смена устройств, эхоподавление на оборудовании и часовой разговор требуют приёмки. Открытие раздела не активирует микрофон. Для первого измеряемого разговора используйте два физических устройства в разных сетях; локальные процессы не заменяют эту проверку.

## Общие системы 5.0.0

Организации, новости и библиотека используют отдельный доверенный onion-сервер. Укажите его адрес и сверенный открытый ключ в сетевых настройках. Развёртывание описано в COMMUNITY-SERVER-5.0.0.md. Почтовый Relay не получает документы общей библиотеки или голосовой plaintext.

Для управления организацией сначала подключите одноразовые коды в разделе безопасности. Обычная первоначальная регистрация второго фактора не заменяет уже действующий фактор. Глобальные критические действия подтверждают два администратора.
