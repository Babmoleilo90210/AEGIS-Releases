# АЕГИС 1.1.1 Demo — Тёмно-зелёная

- Новый цветовой UI preset «Тёмно-зелёная» в Настройки → Внешний вид → Тема.
- Тёмно-зелёные фоны, умеренные зелёные акценты, светлый контрастный текст и зелёные цвета писем во всех страницах единого окна.
- Выбор сохраняется после перезапуска. Все пять прежних тем и «Как в системе» сохранены. Пресеты геометрии и масштабирование продолжают работать независимо.
- Версия клиента, EXE, Setup, AppImage, updater и desktop metadata — 1.1.1.
- E2EE, Relay, protocol 1, identity keys, аккаунты и формат локального зашифрованного хранилища не менялись.
- Добровольный тестовый канал Beta уже предусмотрен опубликованным клиентом 1.1.0. Для Demo подготовлен отдельный unsigned beta manifest; stable feed не меняется.

Это Demo для проверки обновлений, не обязательный security update. Owner-signed нативный переход 1.1.0 → 1.1.1 считается пройденным только после приёмки на Windows 11 и CachyOS KDE. До подписи и публикации владельцем productionReady=false.
