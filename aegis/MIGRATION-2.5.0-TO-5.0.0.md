# Миграция АЕГИС 2.5.0 → 5.0.0

Миграция продолжает существующий механизм `ClientUpgrade`/`ProfileSnapshot`, а не заменяет пользовательское хранилище. Перед открытием существующего профиля для 5.0.0 вызывается `beforeVersionOpen("5.0.0", config, backups)`. Сначала создаётся и проверяется полный снимок зашифрованного vault, отдельных архивов и параметров; только после проверки атомарно записывается marker. Повторное открытие проверяет и использует тот же снимок. Повреждённый или незавершённый снимок не считается успешной резервной копией; исходные данные сохраняются.

Сохраняются identity public/private keys, контакты, письма, вложения, recovery keys и личный архив с независимым паролем. Не меняются протокол существующих писем, FF1, формат архива, параметры Tor, updater и закреплённый публичный ключ подписей обновлений. Пользовательское содержимое не передаётся новым серверным системам или ИИ автоматически.

## Навигация и оформление

Порядок разделов нормализуется в три блока, утверждённых для 5.0.0:

1. Поиск, Профиль, Контакты, Письма, Архив.
2. Взор, Глас, Организации, Новости, Библиотека.
3. Настройки.

Внутри каждого блока сохранён относительный порядок ранее существовавших разделов. Между блоками разделы размещаются согласно новым требованиям владельца. Новые `organizations`, `news`, `library` добавляются однократно. Взор сохраняет внутренний ID `safeweb` и свои отдельные каталоги. Прежние варианты с шестью/семью/восемью разделами продолжают читаться; некорректные, дублирующие и неизвестные ID не принимаются за корректный макет.

Тот же порядок мигрируется во всех сохранённых пользовательских макетах. Палитры, выбранные темы, шрифты, плотность, масштаб, формы и остальные параметры не сбрасываются. При чтении файла оформления оригинальные байты не перезаписываются: новая форма сохраняется только обычным сохранением параметров. Повторное чтение/сохранение/импорт не создаёт дубликатов разделов.

## Голосовые настройки

Голосовой sidecar сохраняет свой путь и шифрование. Схемы 1/2 читаются без изменения файла; независимые входящие/исходящие правила добавляются при сохранении как схема 3. По умолчанию сохраняется разрешение звонков известных незаблокированных контактов; ранее отключённые входящие остаются отключёнными. Организационное исключение по умолчанию выключено. Новый sidecar ограничен прежними квотами и участвует в существующем rekey/снимке vault; при редактировании правил identity и ключ архива не меняются.

Браузерный профиль и установки находятся вне хранилища АЕГИС. Они не переносятся в архив или серверный кэш. Миграция навигации не меняет их каталог и не копирует чужие Firefox cookies, историю или пароли.

## Проверка и откат

Работайте с отдельной копией профиля. Сохраните старую установку, закрыв старый клиент и браузер перед сменой версии. Проверьте marker, целостность снимка, ключевой отпечаток, контакты, письма, архив, темы и порядок разделов. Повторите запуск и сравнение; искусственное прерывание выполняйте только на тестовой копии.

При откате после записи схемы 3 восстановите проверенный снимок через `ProfileSnapshot.restore` после закрытия приложения и получения lock. Предыдущее изменённое состояние сохраняется переименованием, не уничтожается. Старый клиент не обязан читать новые голосовые параметры или одиннадцать разделов. Шифрованный снимок содержит пользовательские данные и остаётся у владельца; его не следует загружать в публичные артефакты.

## Подтверждение

Целевые автоматические проверки включают настоящие сохранение/чтение/повторный импорт макетов 1.5/2.0/2.5, миграцию в три блока, snapshots перед 5.0.0, сохранность identity и ciphertext писем/архива, повторный запуск, отклонение повреждённого snapshot и голосовые правила после rekey. XML и конфигурация прогона: `docs/test-results/5.0.0-glas-migration/`.

Эти локальные проверки не заменяют подписанное обновление с установкой/перезапуском/rollback на Windows 11 и CachyOS KDE. Их результаты для готовых бинарников 5.0.0 должны быть зафиксированы отдельно; прежнее сообщение владельца о проверке 2.5.0 не является испытанием ещё не выпущенного 5.0.0.
