# Настройка клиента CachyOS 0.2.0

Основная инструкция: [README-CACHYOS.md](README-CACHYOS.md).
AppImage включает собственные Java и Tor. Старый системный Tor для обычного запуска не требуется. При миграции освободите порты 19050/19051 от прежнего пользовательского aegis-tor.service; приложение не завершает чужие процессы.
