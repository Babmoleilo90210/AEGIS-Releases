# Интерфейс АЕГИС 2.5.0

Навигация: Поиск → Профиль → Контакты → Письма → Архив → Взор → Глас → Настройки. Существующий пользовательский порядок сохраняется, новый Глас добавляется рядом с Взором. Контурные SVG-значки имеют одинаковые размеры и толщину линии; пользовательские цвета и настройки Appearance Engine сохраняются.

Галерея использует отдельные области preview/name/favorite без абсолютного наложения. Все 16 встроенных пресетов остаются доступными. В архиве внутренние `letter/text/image/pdf/file/folder` отображаются русскими названиями; формат данных не меняется. Основные действия доступны сразу, второстепенные объединены в меню. Управление: защита, резервные копии, обслуживание; выбранная функция открывает компактную панель в основном окне.

Поиск сохраняет одну строку и скрытые фильтры. Настройки сохраняют пять категорий на общей подложке и содержимое ниже них. Профиль ограничен разумной шириной карточки. Верхняя панель, контакты и письма остаются узнаваемыми.

Взор: короткий статус, открытие, адрес и тип сессии; подробности сворачиваются. Глас: поиск/контакт/вызов и встроенная панель разговора; звук, история и криптографические сведения раскрываются по запросу. Отдельные окна звонка/настроек не создаются. Официальный Tor Browser открывает собственное окно ради поддерживаемой архитектуры.

Реальные headless JavaFX screenshots и журналы располагаются в `docs/test-results/2.5.0-ui-followup/` и `docs/test-results/2.5.0-vzor-glas-ui/`. Они созданы приложением, не генератором изображений. Headless Monocle не является Windows 11/CachyOS KDE. Часть старого smoke упирается в ошибку resize backend; она сохраняется в отчёте и не считается чистым PASS.
