Пакет содержит Java 21, собственный Tor и необходимые библиотеки; глобальные Java/Tor не нужны. В native ОС пока не принят: смотрите TEST-REPORT-1.1.0.md. # АЕГИС 1.0.0 для Windows

1. Скачайте **AEGIS-Setup-1.0.0-x64.exe**.
2. Откройте его и завершите установку для текущего пользователя.
3. Запустите **АЕГИС** через меню Пуск.
4. Дождитесь подключения Tor, вставьте адрес `.onion`, выданный владельцем сервера, и нажмите **Подключиться**.
5. Создайте аккаунт или войдите по нику и паролю. Адрес сервера сохраняется.

Java и Tor уже внутри. Отдельно устанавливать Java, Tor Browser или Tor не нужно. Установка и клиент работают без Administrator.

Подписывать файлы, передавать ключ разработчику и выполнять команды перед запуском не требуется. Проверка обновлений по умолчанию выключена; она не блокирует вход и сообщения. Новую версию можно установить вручную поверх текущей, сохранив профиль.

**Без установки:** распакуйте весь `AEGIS-1.0.0-Windows-x64.zip` и откройте `AEGIS.exe` из папки `AEGIS`. Все папки внутри архива должны оставаться рядом с EXE. Для варианта с одним скачиваемым файлом выбирайте Setup EXE.

При первом запуске неподписанного Windows EXE система может показать SmartScreen. АЕГИС не отключает Defender и не обходит эту проверку.

Требования: Windows 10/11 x64. Если встроенный Tor не может подключиться, приложение показывает ошибку и остаётся offline. Публичные входящие порты и firewall настраивать не требуется.

Техническое описание находится в `docs/OPERATIONS-WINDOWS-1.0.0.md`. Реальный запуск на Windows в текущей Linux-среде не проверен; подробный статус указан в отчёте.
