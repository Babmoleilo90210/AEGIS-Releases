# АЕГИС 1.2.0 — Windows 11 x64

Кандидат для нативной приёмки: **productionReady=false**. Java 21, Tor, Snowflake и необходимые DLL включены. Глобальная Java и Tor Browser не нужны.

1. Для установки откройте AEGIS-Setup-1.2.0-x64.exe под обычной учётной записью. Для portable распакуйте весь AEGIS-1.2.0-Windows-x64.zip и запустите AEGIS.exe; один EXE без соседних runtime/tor/app не работает.
2. Дождитесь подключения Tor. Введите выданный владельцем сервера onion hostname и подключитесь.
3. Войдите в существующий аккаунт и разблокируйте локальное хранилище либо создайте новый аккаунт. Не регистрируйте заново существующий nickname и не заменяйте его identity.
4. Добавляйте контакты с проверкой fingerprint. Для двух клиентов 1.2.0 взаимная дружба подтверждается через encrypted signed assertions даже на Relay 0.2.0; до подтверждения показывается ожидание. Публичные профили по-прежнему зависят от возможностей используемого Relay.

Данные сохраняются в %LOCALAPPDATA%\AEGIS, не рядом с EXE. Перед переходом с 1.1.5 прочитайте MIGRATION-1.1.5-TO-1.2.0.md и сохраните полный профиль; identity backup не включает всю переписку. Существующие аккаунты, ключи, письма, TTL, контакты, темы, макеты, сессии, настройки и Tor state сохраняются. Открытый черновик остаётся в памяти и блокирует установку до завершения/отмены.

Обычные письма открываются после E2EE. Дополнительная защита использует ручные letter password/FF1 и финальное действие «Показать результат». Список и ввод секрета не считаются прочтением. «Прочитано» означает подтверждённый показ клиентом, а не доказательство чтения человеком. Обычные receipts можно выключить.

Обычный TTL действует после доставки. Новый режим исчезающих писем доступен только для проверенного совместимого устройства: от 1 минуты до 30 дней после показа. Уже открытые письма могут исчезнуть раньше срока после reboot ОС/недостоверного expiry ledger. App restart в том же boot сохраняет таймер. Экспортированные файлы и скриншоты не удаляются. Полные ограничения — LIFECYCLE-1.2.0.md.

Настройки/профиль/аватар/прогресс находятся в одном главном окне. Масштаб и прежние темы/макеты сохранены. DPI 100/125/150/200% проверяется владельцем по NATIVE-ACCEPTANCE-1.2.0.md. Windows Server CI не заменяет Windows 11.

Администратор и публичный входящий Firewall-доступ не требуются. Только localhost Tor SOCKS 19050/19052, Control 19051 и peer service 19120; Java не подключается напрямую к Интернету при ошибке Tor. Закрытие завершает только собственный Tor. Defender/SmartScreen не отключаются; неподписанный Authenticode EXE может вызвать стандартное предупреждение.

Обновления сохраняют TLS, pinned Ed25519, SHA-256, anti-rollback и подтверждение установки. Подписанный переход на этот candidate ещё NOT_RUN. См. OWNER-OFFLINE-SIGNING-1.2.0.md, TEST-REPORT-1.2.0.md и README.md.
