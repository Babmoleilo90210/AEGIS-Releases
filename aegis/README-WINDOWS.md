# АЕГИС 6.0.0 — Windows11 x64

Проверьте SHA256SUMS и source/build provenance. `AEGIS-Setup-6.0.0-x64.exe` устанавливает программу для текущего пользователя; portable ZIP распаковывается полностью и запускается через `AEGIS.exe`. Не смешивайте JAR/runtime разных версий и не переносите файлы профиля в папку программы.

Первым открывается Core. Настройте доверенные onion-сервисы/публичные ключи, сверьте отпечатки. Создание/привязка Почты и ввод её пароля выполняются отдельным процессом. Общие инструкции — README-6.0.0.md.

Взор и защищённый Obsidian используют штатную Windows Sandbox на поддерживаемой редакции/конфигурации Windows11. Windows Home не объявляется поддержанной для этой изоляции. При недоступной песочнице нет скрытого запуска в ослабленном режиме. Сторонние браузер/Obsidian имеют собственные проверенные источники и обновления.

Обновление проверяет Ed25519, размер, SHA-256, version/tag/URL и anti-rollback. Перед заменой программы закрываются управляемые компоненты и проверяется общий runtime guard. Независимые Взор/личный Obsidian необходимо закрыть отдельно.

Если Setup сохранил `AEGIS.rollback-6.0.0`, Core → Настройки → Обновления предлагает явный возврат предыдущей программы. Проверяются точный каталог установки, PID/образы Core и launcher, reparse points и хеш maintenance helper; helper запускается из отдельного каталога и ждёт освобождения runtime. Почтовый дочерний процесс 6 не вызывает устаревший автоматический rollback1.1.5. Portable, переименованные/неполные установки не получают фиктивно доступный откат.

Старые данные и зашифрованные копии сохраняются. Откат программы не равнозначен совместимости новой базы со старой программой: используйте проверенный снимок. Реальный Windows11 install/update/restart/rollback, Sandbox, звук и масштабирование требуют нативной приёмки. Cross-compiled EXE и тесты файловых контрактов ей не являются.
