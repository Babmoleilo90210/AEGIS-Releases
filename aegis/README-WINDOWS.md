# АЕГИС 1.1.0 — Windows x64

Это кандидат для приёмки, ещё не опубликованный stable release. Нативная Windows 11 приёмка не выполнена. Не заменяйте единственную рабочую копию профиля до резервного копирования.

Удобный вариант — `AEGIS-Setup-1.1.0-x64.exe`: установщик работает от обычного пользователя и создаёт ярлыки. Portable — `AEGIS-1.1.0-Windows-x64.zip`: распакуйте **всю** папку AEGIS и откройте `AEGIS.exe`. Одного EXE без соседних файлов недостаточно. Java 21, Tor, Snowflake и DLL уже внутри; Java и Tor Browser отдельно устанавливать не нужно.

Дождитесь подключения Tor, вставьте `.onion` сервера и нажмите «Подключиться». Создайте аккаунт или войдите. Существующий профиль 1.0.0 сохраняется; не создавайте вместо него новые ключи. На другом устройстве восстановите свою identity backup. Пароль и защищённое локальное разблокирование работают по существующей модели 1.0.0; переход описан в [MIGRATION-1.0-TO-1.1.md](MIGRATION-1.0-TO-1.1.md).

Письма шифруются автоматически на устройстве. Дополнительная защита письма использует вручную заданные новые пароль письма и FF1 code. Защищённый ответ требует новые значения. TTL задаётся рядом с отправкой, начинается после доставки и истекает независимо от открытия письма. Сохранённые вручную файлы и снимки экрана приложение не уничтожает.

«Профиль» меняет только собственный аватар и «О себе». Публичные данные выключены по умолчанию. Дружба требует взаимного добавления с проверенными отпечатками. Relay 0.2.0 предоставляет обычную почту; публичные профили и дружба требуют совместимого Relay 0.3.0. Заблокированные письма не мешают остальной очереди. «Открыть без сети» разблокирует локальную почту без сервера.

Данные находятся в `%LOCALAPPDATA%\AEGIS`, а не рядом с EXE или в Program Files. Не удаляйте этот каталог при обновлении. Updater сохраняет полный профиль, включая ciphertext, настройки, аватары, TTL/receipts, сессию и Tor state. Экспорт идентичности в настройках не является экспортом всей переписки.

Внешний вид → масштаб меняет геометрию всего интерфейса от 80% до 200% сразу, поверх системного DPI. Windows DPI 100/125/150/200% требует нативной приёмки. Пресеты и черновик сохраняются при смене оформления; черновик существует только в памяти до закрытия приложения.

После проверенной установки 1.1.0 updater проверяет подписанные обновления при запуске и каждые 24 часа, загружает с прогрессом и ждёт согласия на установку. Неверная подпись/хеш запрещают установку. Автоматический первый переход из 1.0.0 не заявлен: нужна независимая проверка manifest и ручной установщик.

Administrator и открытие входящих портов не требуются. Почта использует onion-only localhost SOCKS собственного Tor; HTTPS обновлений — отдельный localhost SOCKS того же Tor. Прямого fallback нет. Закрытие завершает только собственный Tor. АЕГИС не отключает Defender/SmartScreen.

При ошибке нажмите индикатор соединения → «Повторить соединение». Технические сведения — в диагностике. Сетевые соединения перечислены в [README.md](README.md), проведённые проверки — в [TEST-REPORT-1.1.0.md](TEST-REPORT-1.1.0.md).
