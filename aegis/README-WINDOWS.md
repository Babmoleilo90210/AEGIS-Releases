# АЕГИС 5.0.0 — Windows 11 x64

**Кандидат; productionReady=false.** Сборка Windows выполнена кросс-компилятором; настоящий Windows 11 в этой среде отсутствует. Работа Setup, аудио, Sandbox, обновления и rollback требует нативной приёмки.

1. Проверьте SHA-256 по SHA256SUMS и подпись владельца, когда она будет предоставлена отдельно.
2. Установите AEGIS-Setup-5.0.0-x64.exe в свой пользовательский каталог либо распакуйте полный portable ZIP. Не смешивайте файлы разных версий.
3. Запустите AEGIS.exe обычным пользователем. Java 21, Tor и аудиобиблиотеки включены. Регистрировать системные DLL и запускать приложение администратором не требуется.
4. Сохраните старую установку и резервные копии до проверки миграции.

## Взор

Требуется Windows 11 24H2+ x64 Pro/Enterprise/Education, доступная виртуализация, включённый Windows Sandbox и актуальный официальный Windows Sandbox CLI. **Windows Home для Взора не поддерживается.** Клиент проверяет предпосылки и сообщает понятную ошибку, не ослабляя изоляцию. Включение разрешённого системного компонента предлагается внутри Взора через штатное UAC и проверенный DISM. Само приложение остаётся без административных прав; неподдерживаемая редакция или отсутствующий официальный Sandbox CLI не обходятся ослабленным запуском.

«Открыть Взор» получает официальный Tor Browser и `.asc` через Tor АЕГИС. Проверка закреплённого OpenPGP-ключа предшествует исполнению подписанного installer. Installer ограничен собственным Job Object. Браузер работает в отдельной Sandbox VM; clipboard, camera/audio input, printers и vGPU отключены. Приватное хранилище АЕГИС не отображается в VM. Нативные проверки этих API ещё NOT_RUN.

## Глас

Выберите микрофон и устройство вывода в «Глас» → «Звук и входящие вызовы». Windows может отдельно запретить доступ настольных приложений к микрофону; используйте настройки конфиденциальности ОС. После принятия звонка микрофон включается отдельной кнопкой. Проверка микрофона добровольная, ограничена 15 секундами, не записывает и не передаёт звук. Отсутствующий выбранный микрофон не заменяется другим автоматически.

При обновлении АЕГИС останавливает собственные Взор и звонок, создаёт снимок профиля и запускает прежний механизм обновления с проверками подписи/хеша/версии. Полный нативный E2E и автоматический rollback ещё не пройдены. Не удаляйте rollback-каталог до приёмки.

## Общие системы 5.0.0

Организации, новости и библиотека используют отдельный доверенный onion-сервер. Укажите его адрес и сверенный открытый ключ в сетевых настройках. Развёртывание описано в COMMUNITY-SERVER-5.0.0.md. Почтовый Relay не получает документы общей библиотеки или голосовой plaintext.

Для управления организацией сначала подключите одноразовые коды в разделе безопасности. Обычная первоначальная регистрация второго фактора не заменяет уже действующий фактор. Глобальные критические действия подтверждают два администратора.
