# АЕГИС 2.5.0 — «Взор и Глас»

Кандидат для приёмки, `productionReady=false`. Stable и подписной feed не опубликованы.

- «Взор»: автоматическое получение официального Tor Browser и OpenPGP-подписи через Tor, проверка закреплённого ключа, версии и архитектуры, отмена, атомарная установка, восстановление и повторное удостоверение изменённой установки. Ручной импорт сохранён как резервный путь.
- «Глас»: настоящая реализация личных звонков с onion P2P, взаимно аутентифицированным TLS 1.3, существующими Ed25519 identity, Opus, SpeexDSP AEC/NS, ограниченными очередями, восстановлением и добровольной зашифрованной историей. Микрофон включается явно после принятия и аутентификации.
- Единые контурные значки, русские названия, восемь переставляемых разделов. Safe Web переименован во «Взор» с сохранением внутреннего ID и параметров.
- Исправлена комплектная Java: добавлены русские данные локали для дат, календаря и чисел, проверены vendorSHA и все файлы runtime.
- Исправлены пересечения избранного в галерее всех 16 пресетов, русские типы архива, компактное управление архивом с вложенными панелями и отображение меню при масштабе.
- Сохранены компактный поиск, пять категорий настроек с содержимым ниже, контакты, письма и утверждённая верхняя панель.
- Исправлены crash-safe публикация аватара, dirty-generation acknowledgement и очистка кэша контактов.
- Добавлены миграция навигации 6/7→8 без сброса порядка, предварительный полный снимок профиля, проверки idempotency и прерванного снимка.
- Генератор manifest обеспечивает `tag == "v" + version` и совпадающие release URL; старые парсеры проверяются автоматически. Ed25519, SHA-256, anti-rollback и pinned public key сохранены.

Обязательная нативная приёмка Windows 11/CachyOS KDE, официальный браузер, DNS/IP/WebRTC-измерения, разговор двух физических устройств и updater E2E остаются незавершёнными. Подробности в TEST-REPORT-2.5.0.md и RELEASE-GATES-2.5.0.json.
