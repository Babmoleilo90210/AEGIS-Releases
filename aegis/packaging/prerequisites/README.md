# Системная подготовка Взора 5.0.0

Повышенные права получает только уже установленный системный менеджер и только для фиксированной операции. Отдельный скачиваемый root-helper или общая привилегированная служба АЕГИС не требуются.

## CachyOS / Arch Linux

`SandboxPreparation` проверяет root-owned `/etc/os-release` (обычный symlink на root-owned `/usr/lib/os-release` допустим) и принимает только `ID=cachyos` или `ID=arch`. `ID_LIKE` не используется для расширения списка поддерживаемых систем.

Единственный разрешённый argv:

```text
/usr/bin/pkexec --disable-internal-agent --user root /usr/bin/pacman -S --needed --noconfirm -- bubblewrap slirp4netns xorg-server-xephyr xorg-xwayland gtk3 dbus-glib
```

Не добавляйте сюда пользовательские аргументы, `--config`, `--root`, `--hookdir`, shell, AUR или отключение проверки подписей. Политика и доверенные репозитории pacman принадлежат администратору ОС. Если системная база устарела или занята другая транзакция, установка завершается ошибкой с понятной причиной; АЕГИС не выполняет рискованное частичное `-Sy` или полное `-Syu` без отдельного назначения.

Окружение вызова очищено до PATH=/usr/bin:/bin и LANG=C.UTF-8; рабочий каталог `/`. Полный путь pkexec/pacman и предки проверяются на владельца root и отсутствие group/other-write. Polkit использует графический агент текущего сеанса KDE; внутренний терминальный ввод пароля отключён. Отсутствие Polkit не обходится sudo или собственной формой пароля.

## Windows 11

Путь Windows получается из системного API, не из PATH/SystemRoot пользователя. Проверенный Authenticode системного `System32/Dism.exe` обязателен; WinVerifyTrust загружается из `System32/wintrust.dll`, с cache-only политикой проверки подписи. Затем ShellExecuteEx с verb=runas вызывает только:

```text
/Online /Enable-Feature /FeatureName:Containers-DisposableClientVM /All /NoRestart /Quiet
```

Нужны x64, build 26100+, поддерживаемая Pro/Enterprise/Education и аппаратная виртуализация. Home не обходится. Код 3010 отображает необходимость перезагрузки. Microsoft CLI `wsb.exe` проверяется отдельно по защищённому Microsoft App Execution Alias; его отсутствие после servicing не считается исправленным автоматически.

## Проверки и отмена

Тесты `SandboxPreparationTest` и `SandboxDiagnosticsTest` не устанавливают пакеты и не запрашивают повышения прав. Они проверяют границу передачи аргументов и реальные безвредные дочерние процессы. Нативные Polkit/UAC/DISM проверки требуют отдельных Windows/Cachy окружений.

Нельзя принудительно завершать подтверждённую OS-транзакцию ради отмены загрузки браузера. Отмена откладывается до завершения транзакции; повторный запуск блокируется пока она жива. Прогресс здесь неопределённый и соответствует фактическому этапу, не выдуманным процентам.

Пакеты/компоненты ОС загружаются системными менеджерами по сетевой политике ОС, которая может использовать прямые соединения. Этот отдельный этап подготовки не считается анонимным браузерным трафиком; Tor-only ограничения приложения не отключаются.
