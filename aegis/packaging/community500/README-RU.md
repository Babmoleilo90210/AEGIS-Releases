# Отдельные серверные пакеты АЕГИС 5.0.0

Это рабочие Java-модули общей системы и узла новостей для операторского испытания. Они требуют полноценную Java 21 и не содержат пользовательскую JavaFX-сборку, production-конфигурацию, серверные identity keys, TOTP-seeds, KEK, API credentials или пользовательские данные. Существующий Relay не изменяется. Пакеты сами не устанавливают службы, Tor и модели и не выполняют команды с повышенными полномочиями.

Центральный пакет: `bin/community-server --init|--inspect|--serve ...`. Рабочий узел: `bin/news-worker --generate-key ...` либо `--server ... --server-key ... --worker-key ... --tor-socks ... [--once]`. Дополнительный Windows launcher предусмотрен для центрального CLI; полноценное серверное развёртывание Windows и политика ACL подлежат отдельной приёмке. Основной операторский сценарий — отдельная Linux-учётная запись и systemd.

Начните с `SERVER-DEPLOYMENT-PROPOSAL-5.0.0-RU.md`. Конфигурации systemd и Tor приведены как предложения для согласования, не активированы автоматически. Java должна включать `java.sql`, `java.xml`, `java.desktop`, `java.net.http`, `jdk.httpserver`, `jdk.crypto.ec`; произвольный урезанный JRE не является проверенной заменой. Java 21 не включена в архивы и не загружается launcher-скриптом.

Проверьте `SHA256SUMS`, `SERVER-BUILD-PROVENANCE-5.0.0.json`, исходный commit и контрольные суммы с доверенным пакетом владельца. Сам файл SHA256SUMS без доверенного канала или подписи не доказывает подлинность. Скрипт сборки заново компилирует серверные модули из чистого Git HEAD и побайтно сверяет классы/ресурсы с упаковываемыми JAR; это не заменяет нативную и сетевую приёмку.

Рабочий узел содержит JAR общих серверных классов только для повторного использования безопасных парсеров/контрактов. Полномочия определяются отдельной служебной identity на сервере, а не наличием классов в classpath. Узлу нельзя выдавать identity администратора, доступ к центральной БД, личным профилям или ключам пользователя. HTTP-сервер дополнительно ограничивает зарегистрированного worker только операциями claim/complete/fail.
