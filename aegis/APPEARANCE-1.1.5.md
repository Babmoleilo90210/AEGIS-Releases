# Оформление АЕГИС 1.1.5

Настройки → Внешний вид открывает страницу в том же окне.

Нажмите миниатюру для временного предпросмотра. «Применить» сохраняет выбор. «Отмена» или возврат восстанавливает прежнюю тему. Звезда добавляет оформление в избранное, строка поиска и категория сокращают галерею.

Дополнительные секции раскрываются по одной необходимости: цвета и пользовательская тема, шрифты, размеры и доступность, навигация, почтовый центр и макеты, фон, автоматическая смена. Встроенный пресет редактируется только через собственную копию. Нечитаемые сочетания основного текста и поверхностей отклоняются (контраст 4.5:1, вторичный текст 3:1).

Для каждого из трёх видов текста выберите системный шрифт, размер 11–26 и насыщенность. Отсутствующий шрифт при запуске включает безопасное оформление; исходный файл остаётся доступен для восстановления. Масштаб 80–200% масштабирует всё содержимое Scene и применяется дополнительно к масштабу ОС. Плотность и интервалы независимы от него.

Настройте расположение навигации и порядок кнопок. Настройки всегда входят в допустимый набор; полностью убрать их нельзя. При узком окне подписи и второстепенные панели сворачиваются. Папки доступны также через селектор над списком.

Макеты «Две колонки», «Три колонки», «Компактный», «Пользовательский» используют те же компоненты. Перетаскивание разделителя и ползунки меняют пропорции. Макет можно именовать, сохранить, переключить, экспортировать и вернуть стандартный.

Фоны выбираются только с устройства: JPG/PNG/WebP до 5 МБ. Исходный размер ограничен 16384 по стороне и 64 мегапикселями; декодирование с subsampling приводит изображение к максимуму 2048 по стороне. Внутренняя копия — PNG без исходных метаданных. Изображение не загружается в Relay. Поверх него используются читаемые панели. Прозрачные пресеты не размывают фон; при отсутствии поддержки или повышенном контрасте панели непрозрачные.

Экспорт темы/макета — JSON schema 1: только разрешённые цвета, шрифты, числа, перечисления, порядок и признаки. CSS, скрипты, URL ресурсов, пути к произвольным файлам, ключи, пароли и переписка не экспортируются и не принимаются при импорте. **Фоновое изображение не переносится в JSON**: на другом устройстве выберите его отдельно. Лимит файла обмена — 64 КиБ.

Safe Appearance Mode не меняет vault. Внизу оформления доступны сброс и восстановление резервной копии. Перед сохранением применяется атомарная запись с backup. Расписание использует локальное время; системная тема проверяется раз в 30 секунд.
