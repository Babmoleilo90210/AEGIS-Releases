# Миграция 2.0.0 Beta → 2.5.0

Перед открытием существующего `state.vault` приложение вызывает `ClientUpgrade.beforeVersionOpen("2.5.0", ...)`. Создаётся и проверяется полный снимок зашифрованного профиля и параметров, включая расположение отдельного архива. Marker записывается только после проверки. При повторном запуске существующий снимок проверяется и используется повторно. Повреждённый снимок не принимается за исправный; исходный профиль не удаляется.

Ed25519 identity, пароли писем, FF1, recovery keys и формат архива не заменяются. Safe Web сохраняет внутренний ID `safeweb` и собственные каталоги, меняется отображаемое имя на «Взор». Глас добавляется после Взора без сброса остальных разделов. Тема, пользовательские палитры, макеты, Tor и updater остаются на прежнем месте.

Параметры/история звонков — новый необязательный шифрованный `voice-v1.vault` с отдельным AAD. История отключена по умолчанию. Ошибка этого sidecar блокирует звонки, сохраняя доступ к исправному основному хранилищу. Сам файл не перезаписывается автоматически.

## Порядок проверки

1. Закройте старое приложение. Скопируйте целиком профиль, настройки и отдельный каталог архива на защищённый носитель.
2. Для испытаний работайте с копией. Сохраните установку 2.0.0 и её точную конфигурацию.
3. Откройте копию в 2.5.0; проверьте marker и успешную проверку снимка. Не передавайте резервную копию разработчику: она содержит пользовательские данные.
4. Сравните identity public key, контакты, письма, вложения, архивные записи, темы, порядок навигации и настройки Tor.
5. Перезапустите 2.5.0 и убедитесь, что повторная миграция не создаёт новый порядок или новые identity.
6. Проверьте искусственно прерванную миграцию только на отдельной копии. Восстановление выполняйте штатным ProfileSnapshot/Updater rollback после закрытия приложения и получения lock.

Автоматические проверки локального ciphertext/ключей/писем/архива и навигации выполнены. Нативная установка поверх настоящего 2.0.0 с updater, перезапуском и rollback ещё NOT_RUN. Не считать unit-проверку полным upgrade E2E.
