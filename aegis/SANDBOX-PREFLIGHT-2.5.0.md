# Взор 2.5.0: предварительная проверка песочницы

`SandboxPrerequisites.check()` — проверка доступности перед ожиданием Tor и скачиванием браузера. Она только читает сведения о системе и возвращает типизированный `SandboxPrerequisites.Failure`: `code()` и фиксированное русское пояснение. Пользовательские пути, входные строки и сообщения вложенных native/filesystem исключений в сообщение не включаются. Приложение не включает компоненты ОС, не запрашивает повышение прав и не запускает обычный браузер вместо песочницы.

Linux: поддерживается x86_64; проверяются фиксированные `/usr/bin/bwrap`, `/usr/bin/slirp4netns`, `/usr/bin/Xephyr`, владелец root и отсутствие записи для группы/остальных, включая каталоги исходного и разрешённого пути. Требуется локальный `DISPLAY` вида `:0`/`:0.0` и настоящий локальный Unix-сокет X11/Xwayland. Для KDE Wayland нужен Xwayland. Не запускаются команды из PATH. Предварительная проверка не доказывает разрешение user namespaces или доступ к X-серверу: их фактическая работа выясняется только при запуске изолированного контекста.

Windows: требуется x64, сборка не ниже 26100 (Windows 11 24H2+), редакция Pro/Enterprise/Education, установленный `System32/WindowsSandbox.exe` и официальный App Execution Alias `wsb.exe`. Windows Home получает отдельное сообщение о несовместимости. Проверяется принадлежность alias пакету Microsoft Windows Sandbox, защищённый путь в Program Files/WindowsApps и наличие целевого CLI. Предварительная проверка не запускает CLI, VM или браузер и не создаёт временный каталог. При настоящем запуске существующий контроллер дополнительно выполняет ограниченный `wsb --version`, создаёт собственную VM и проверяет её идентификатор; работа виртуализации не объявляется доказанной по одному наличию файлов.

Оба backend используют тот же `requireEnvironment()` при настоящем запуске, поэтому ранняя проверка интерфейса не заменяет проверку перед выполнением. macOS и остальные неподдерживаемые ОС возвращают явную ошибку поддержки.

Проверки JDK 21: 20/20 PASS, включая пять новых тестов политик платформы/редакций/сборок/DISPLAY/прав и отсутствующих зависимостей, а также существующие 15 тестов Linux/Windows backend. Фактический read-only результат в этом окружении сохранён отдельно: `docs/test-results/2.5.0-sandbox-preflight/environment-precheck.txt`. Нативный запуск Windows 11 и CachyOS KDE, VM, namespaces и реальный Tor Browser этим набором не проверялись: **NOT_RUN**.
