# Изменения интерфейса 2.0.0

Основа — шесть реальных пользовательских скриншотов 15 октября 2026, включая настройки с красными рамками и стрелкой. Сохранены верхняя панель, контакты и основная компоновка писем.

Настройки: пять групп на общей подложке; уточняющие действия и содержимое ниже, без боковой колонки. Архив: Добавить / Новая папка / Папки / Ещё; избранное, корзина, вид/сортировка, управление и блокировка доступны в меню. Список/таблица/карточки сохранены. Поиск: строка имени/темы/содержимого, быстрые категории, скрытые фильтры отправителя/темы/дат/типа/направления. Полный текст проверяется в памяти только для обычного аутентифицированного письма; letter password/FF1 не раскрываются. Сохраняется прежний лимит 200 результатов.

Профиль ограничен по ширине, содержимое прокручивается; кнопки используют общие theme tokens. Nickname остаётся неизменяемым: существующий протокол не поддерживает безопасное переименование. Реализация этого требования требует отдельного согласования Relay, см. PROFILE-SYNC-2.0.0.md.

Общие размеры button/toggle/menu заданы в em с едиными отступами и радиусами Appearance Engine. Сохранены 16 пресетов, формы, кириллические шрифты, импорты/экспорты и макеты. Перестановка навигации сохранена, Safe Web добавляется после Архива; при отсутствии Архива — перед Настройками. Валидация принимает семь разделов.

Скриншоты в evidence/screenshots получены из настоящего JavaFX с синтетическими данными через Monocle. Это headless-проверка, не Windows 11 и не CachyOS KDE. Нативная оценка при 100/125/150/200%, максимизации, длинных подписях и разных темах остаётся обязательной. Проверка каждого UI-01…26 указана отдельно в FINAL-VERIFICATION-2.0.0.json.
