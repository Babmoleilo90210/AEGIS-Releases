# 2.0.0 — Safe Web & Complete Interface Refinement

Текущий статус — кандидат для проверки, `productionReady=false`; Stable не опубликован.

- Safe Web встроен в навигацию. Встроенный Java OpenPGP verifier проверяет официальный пакет до распаковки/запуска; используется отдельный полный Tor Browser со своим Tor.
- Реализованы обычные и временные сессии, отдельные trusted templates/receipts, атомарная подготовка, блокировка управляющего экземпляра и сохранение владения при ошибке остановки.
- Linux: bubblewrap, private network namespace/slirp и вложенный Xephyr. Windows: официальный Windows Sandbox CLI, собственный VM ID и восстановление после сбоя. Требуются Windows11 24H2+ Pro/Enterprise/Education; Home этим backend не покрыт.
- Реализованы явное открытие выбранной ссылки письма, строгая проверка URL, загрузки и защищённый snapshot перед импортом существующим EncryptedArchive. Автоматического запуска файлов нет.
- Настройки объединены в пять категорий на общей подложке; содержимое ниже, единая прокрутка, длинные русские подписи и масштабирование. Возвращены все категории уведомлений и доступ к прежним функциям.
- Архив: основные действия и меню дополнительных; сохранены список/таблица/карточки. Поиск: одна строка и шесть скрытых фильтров; исправлен отправитель исходящих писем.
- Профиль: компактная карточка; исправлены устаревшее изображение контакта, удаление/скрытие аватара и гонка публикации. Метаданные изображения удаляются при сохранении и публикации старых данных.
- Сохранены 16 пресетов, пользовательские темы/макеты, навигационный порядок и одобренная верхняя панель. Добавлены проверки миграции, cache/replay/privacy, UI 800×600 при100–200%, runtime packaging и lifecycle.

Открытые обязательные пункты: фактическая установка/версия официального Tor Browser; HTTPS/onion/DNS/WebRTC/packet capture и границы ОС; совместимость официального MAR updater; нативная приёмка Windows11/CachyOS Wayland/X11; полный owner-signed updater 1.5→2.0 и rollback; реальный двухаккаунтный обмен аватарами через Tor; согласованное серверное переименование nickname; определение требований к другим редакциям Windows. Попытки настоящего Tor в доступной сети заблокированы до готовности — это не PASS профилей. Production Relay, Stable feed и release keys не менялись.
