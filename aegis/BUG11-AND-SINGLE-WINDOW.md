# АЕГИС 1.1.0 — BUG-11 и единое окно

## Причина BUG-11

`SignedManifest.verifyWithKey` отклонял version < установленной версии / локального floor. `UpdateService.check` перехватывал все исключения и показывал сообщение об ошибке Tor. Production stable=1.0.0 при установленном 1.1.0 воспроизводит этот путь даже при корректных TLS и Ed25519. Предупреждение JavaFX об unnamed module к этой политике не относится.

## Исправление

Сначала Ed25519 над точными байтами, затем строгая схема. Проверка доступности обновления допускает старый подписанный feed и сообщает «Новых обновлений нет». Старый feed не создаёт системное письмо, не скачивается и не изменяет highest version. Загрузка/подготовка/отдельный updater сохраняют строгую защиту от отката. Pinned release public key сохранён.

`UpdateDiagnostic` различает TRANSPORT, TLS, HTTP, SIGNATURE, SCHEMA, POLICY, STORAGE, CANCELLED. В технических сведениях и ограниченном приватном лог-файле только категория, стабильный код и класс исключения. Нет URL с токенами, cookie, stack trace, паролей или payload.

`TorHttpsClient` продолжает использовать SOCKS5 hostname через 127.0.0.1:19052, системное хранилище доверенных сертификатов встроенного Java 21, TLS 1.2/1.3, SNI и проверку HTTPS hostname. Каждый редирект проверяется по allowlist. Переписка остаётся на onion-only 19050. Прямого fallback нет.

## Одно окно

`InWindowDialog`, `InWindowAlert`, `InWindowTextInput`, `InWindowFileChooser` заменяют дополнительные Stage, JavaFX Dialog/Alert и системные file dialogs страницами основной Scene. Настройки, оформление, профиль, инструменты, пароли, backup, выбор вложений, crop, подтверждения и просмотр писем используют ту же панель window controls. Вложенные страницы возвращаются назад; закрытие родителя закрывает дочерние страницы. Выход закрывает все страницы. Стандартные выпадающие списки и контекстные меню остаются кратковременными элементами управления, а не отдельными окнами приложения.

Страница выбора файлов работает без запуска внешнего менеджера файлов, автоматического просмотра или сетевой загрузки. Экспорт не перезаписывает существующий файл без отдельного выбора нового имени.

## Проверки

Локальный Java 21/JUnit: 104 теста, 103 PASS, 1 SKIP (Windows DPAPI на Linux). JavaFX Monocle: ClientUiRegressionSmoke, Aegis11UiSmoke, SingleWindowSmoke, MessengerSmoke — PASS. Это не нативная проверка Windows 11 / CachyOS KDE.

`Bug11RealTorProbe` проверяет точные пакеты, встроенный Tor, настоящий production feed read-only, TLS truststore, pinned Ed25519, старую схему и состояние updater. CI запускает before/after на Linux и Windows; результат включается отдельным архивом доказательств. При недоступности внешней сети проверка не отмечается PASS.

## Ограничения выпуска

Production Relay, feed, onion identity и release private key не изменяются. Бинарные файлы пересобираются; требуется новый manifest с новыми SHA-256 и повторная офлайн-подпись владельца. Старую подпись использовать нельзя. `productionReady=false` до обязательной нативной приёмки Windows 11 и CachyOS KDE Wayland/X11, миграции/restart/rollback и полного межплатформенного E2E.
