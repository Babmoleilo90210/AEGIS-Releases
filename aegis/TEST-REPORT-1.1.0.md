# Проверки АЕГИС 1.1.0

Кандидат; productionReady=false. Архивные 54 теста 1.0.0 и 16 release/security tests изучены, но не выдаются за проверку нового клиента. Изменённые исходники собираются на Java 21.

Текущие JUnit XML: 98 тестов; 97 PASS, 1 Windows DPAPI SKIP в Linux. Отдельные 16 Python release/security tests PASS. JavaFX Monocle проверяет всю геометрию Scene на 80/100/125/150/200%, сохранение масштаба, черновиков и файлов, центральный профиль и неизменяемый nickname, масштаб диалогов и один window chrome. Compatibility matrix: выпущенный client-core 1.0.0 → независимо собранный Relay 0.2.0, 1.0.0 → 0.3.0, 1.1.0 → 0.2.0 — PASS. Подтверждены двусторонние защищённые письма, offline, 7 типов вложений, AES ZIP, ACK, replay/dedup, TTL и перезапуск процессов. К одной SQLite применена 0.2 → 0.3 миграция: хеши строк users/mailbox/receipts не изменились. Старый Relay повторно открыл мигрированную БД и доставил обычное письмо. Опубликованный серверный бинарник не выдаётся за проверенный: Relay 0.2.0 для матрицы компилируется из проверенного архива исходников.

Отдельно проверен отзыв friendship consent после удаления контакта offline и повторной авторизации. Состояние отзыва хранится зашифрованно и синхронизируется даже после удаления контакта. Скрытие профиля распространяется при следующем online sync; оно не уничтожает чужие уже сделанные копии.

Нативная приёмка Windows 11, KDE Wayland/X11, live Tor Direct/Snowflake, внешний Relay и reboot, установщик/restart/rollback — NOT RUN. Монокль, loopback SOCKS harness и Linux CI не считаются этими проверками. Проверки staging используют синтетические аккаунты и временную SQLite; production VPS не затронут.
