# Скачать АЕГИС 1.0.0 на CachyOS

**Релиз ещё не опубликован.** Сборки готовы к финальной приёмке; приведённые ниже адреса заработают после публикации v1.0.0.

После выхода версии:

- [AppImage для CachyOS x86_64](https://github.com/Babmoleilo90210/AEGIS-Releases/releases/download/v1.0.0/AEGIS-1.0.0-CachyOS-x86_64.AppImage).
- [Контрольные суммы SHA-256](https://github.com/Babmoleilo90210/AEGIS-Releases/releases/download/v1.0.0/SHA256SUMS).
- [Страница релиза](https://github.com/Babmoleilo90210/AEGIS-Releases/releases/tag/v1.0.0).

1. Скачайте AppImage через браузер.
2. В свойствах файла разрешите выполнение и откройте его. Если удобнее терминал, выполните команды ниже из каталога загрузок.
3. Дождитесь подключения встроенного Tor, вставьте выданный владельцем `.onion` и нажмите «Подключиться».
4. Создайте аккаунт или войдите по нику и паролю; затем добавьте контакт и сверьте отпечаток другим каналом.

```sh
chmod +x AEGIS-1.0.0-CachyOS-x86_64.AppImage
./AEGIS-1.0.0-CachyOS-x86_64.AppImage
```

Java, Tor Browser и отдельный Tor устанавливать не нужно. Не запускайте клиент через sudo.

Проверка скачанного AppImage, из папки загрузок:

```sh
sha256sum AEGIS-1.0.0-CachyOS-x86_64.AppImage
```

Сравните результат со строкой AppImage в `SHA256SUMS`. Контрольная сумма проверяет совпадение файла; она не заменяет проверку подписи.

## Подробности эксплуатации


Скачайте AEGIS-1.0.0-CachyOS-x86_64.AppImage. Разрешите выполнение в свойствах файла и откройте его. Команда для первого запуска, если удобен терминал:

```sh
chmod +x AEGIS-1.0.0-CachyOS-x86_64.AppImage
./AEGIS-1.0.0-CachyOS-x86_64.AppImage
```

Java 21 runtime, Tor, Lyrebird и libsodium находятся внутри. Tor Browser/Java устанавливать не нужно. На системах без FUSE AppImage поддерживает стандартный `--appimage-extract-and-run`; это распаковывает программные файлы, а профиль остаётся постоянным вне образа.

Если ранее установлен AppImage в `~/.local/opt/aegis/`, АЕГИС предложит «Обновить до 1.0.0». После согласия закрывается только старый клиент с подтверждённым APPIMAGE-путём, создаётся полная зашифрованная копия профиля. Войдите обычным паролем аккаунта; если старый vault имел другой пароль, введите его один раз. После успешной миграции AppImage заменяется атомарно, обновляются иконка и ярлык, запускается установленная 1.0.0. Если миграция не удалась, прежний образ не заменяется.

Постоянный ярлык запускает `~/.local/opt/aegis/AEGIS.AppImage`; прежний образ сохраняется для отката. Обнаруживаются этот путь и единственный файл `AEGIS-0.3.0*.AppImage` в том же каталоге. Неоднозначные/нестандартные ручные установки не заменяются автоматически.

Имеющиеся каталоги сохраняются: настройки `~/.config/aegis/client.properties`, vault по `storagePath` (старый стандарт `~/.local/share/aegis`), служебный профиль `~/.local/share/aegis-app`. Backup: `~/.local/share/aegis-app/backups`. Tor cache/state: `~/.local/share/aegis-app/tor/state`, постоянный между запусками и вне AppImage mount.

GUI появляется сразу. Tor подключается в фоне, затем автоматически проверяет сохранённый сервер. Адрес .onion нужен только при первом запуске или выборе «Другой сервер». Для входа достаточно ника и пароля аккаунта; пароль письма и код FF1 остаются отдельными.

Контакты выбираются в поле «Кому» с поиском. Несколько файлов любых типов помещаются в прежний E2EE; общий предел по умолчанию 16 MiB. Получатель скачивает один AES-256 ZIP с паролем письма. Старые письма 0.3/0.2 читаются; для новых писем v4 обоим участникам нужна 1.0.0.

Пять тем находятся в настройках. Технические порты, режимы и логи — только в диагностике. Системный torrc не читается, root не требуется, clearnet fallback отсутствует. Правила firewall не меняются; дополнительный kill switch описан в FIREWALL.md.

JavaFX popup проверен локально через Monocle. Настоящая CachyOS, KDE Wayland/X11, запуск без системной Java и связь с VPS в этой среде не проверены; см. TEST-REPORT-1.0.0.md.

JavaFX21 использует desktop GTK3/fontconfig и XWayland при сессии Wayland. Эти обычные системные компоненты desktop CachyOS не подменяются bundled runtime; минимальные установки без них требуют отдельной native проверки. Linux updater использует имеющиеся libc2.36+ и kernel pidfd5.3+ через уже включённую JNA, без дополнительных внешних служб.

## Новые настройки 1.0.0

XDG_DATA_HOME и XDG_CONFIG_HOME поддержаны; HOME используется при отсутствии переменных. Профиль находится вне AppImage mount. Настройки интерфейса и encrypted avatars сохраняются отдельно от binaries.

«Запомнить вход» использует libsecret / org.freedesktop.secrets, доступный через KWallet или другой Secret Service текущей desktop-сессии. При недоступном/заблокированном provider сессия не сохраняется в открытом виде, обычный вход паролем остаётся доступным. Сохранённое локальное разблокирование действует 7 суток; relay token только 12 часов, reboot relay его сбрасывает. Для нового сетевого входа нужен account password. Дополнительный plaintext пароль для восстановления token не сохраняется.

Настройки → Внешний вид: пять пресетов и custom JSON, размеры/плотность/preview/sidebar. Профиль/Контакты: локальные bounded PNG/JPEG/WebP аватары, без внешних URL и автоматической отправки. Селекторы используют отдельный JavaFX popup window. На Wayland JavaFX21 работает через XWayland; реальная KDE приёмка остаётся обязательной.

Настройки → Обновления: pinned Ed25519 manifest, notes/history, progress и cancel, stable/beta. Проверка и загрузка через собственный Tor, direct HTTPS запрещён. После проверок updater копируется вне mount, ждёт старый PID и атомарно заменяет ~/.local/opt/aegis/AEGIS.AppImage через .new/.old; новая программа подтверждает startup, при ошибке выполняется rollback. После успеха создаётся/обновляется постоянный KDE desktop entry. Пользовательский профиль не заменяется. Неподписанный ещё stable канал отклоняется.
