# Скачать АЕГИС 1.0.0 на Windows

**Релиз ещё не опубликован.** Сборки готовы к финальной приёмке; приведённые ниже адреса заработают после публикации v1.0.0. Не считайте отсутствие файла признаком необходимости отдельно устанавливать Java или Tor.

После выхода версии:

- [Установщик Windows x64](https://github.com/Babmoleilo90210/AEGIS-Releases/releases/download/v1.0.0/AEGIS-Setup-1.0.0-x64.exe).
- [Portable ZIP Windows x64](https://github.com/Babmoleilo90210/AEGIS-Releases/releases/download/v1.0.0/AEGIS-1.0.0-Windows-x64.zip).
- [Контрольные суммы SHA-256](https://github.com/Babmoleilo90210/AEGIS-Releases/releases/download/v1.0.0/SHA256SUMS).
- [Страница релиза](https://github.com/Babmoleilo90210/AEGIS-Releases/releases/tag/v1.0.0).

1. Выберите Setup для установки или ZIP для распаковки.
2. В варианте Setup запустите установщик обычным пользователем. В варианте ZIP распакуйте весь архив и запустите `AEGIS.exe`; папки runtime, tor и app оставьте вместе.
3. Дождитесь подключения встроенного Tor. Вставьте выданный владельцем адрес `.onion` и нажмите «Подключиться».
4. Создайте аккаунт или войдите по нику и паролю. Адрес сервера сохранится для следующих запусков.
5. Добавьте контакт по нику и сверьте отпечаток другим каналом. Для защищённого письма задайте пароль письма, код FF1 и срок удаления.

Java, Tor Browser и отдельный Tor не нужны. Administrator и публичные входящие порты не требуются. Не отключайте Defender ради приложения.

Для проверки файла в PowerShell, из папки загрузок:

```powershell
Get-FileHash .\AEGIS-Setup-1.0.0-x64.exe -Algorithm SHA256
```

Сравните результат с соответствующей строкой `SHA256SUMS`. Контрольная сумма проверяет совпадение файла; она не заменяет проверку подписи.

## Подробности эксплуатации


Запустите **AEGIS-Setup-1.0.0-x64.exe**. Java, Tor Browser и отдельный Tor не нужны. Установка выполняется для текущего пользователя, без Administrator, в `%LOCALAPPDATA%\Programs\AEGIS`. В меню Пуск останется один ярлык «АЕГИС»; ярлык рабочего стола можно выбрать отдельно.

Если установлена 0.3.0, Setup определит версию, предложит обновление, попросит закрыться только её окну и создаст резервную копию зашифрованных данных. Старые программные файлы сохраняются для отката. Другие процессы Java/Tor не завершаются по имени.

Откройте АЕГИС. Tor подключается в фоне: ник и пароль можно вводить сразу. Сохранённый сервер подключается автоматически. При первом запуске вставьте выданный .onion и нажмите «Подключиться». Для изменения есть «Другой сервер».

Вход: ник и **один пароль аккаунта**. Если в 0.3.0 был другой пароль хранилища, при первом входе понадобится один дополнительный ввод старого пароля. После проверки серверного входа АЕГИС переносит идентичность, контакты и письма в хранилище с новым ключом. Повторная регистрация не требуется. Неправильный старый пароль не создаёт пустой аккаунт. Подробнее: MIGRATION-0.3-TO-1.0.md.

Portable: распакуйте **весь** AEGIS-1.0.0-Windows-x64.zip и запустите AEGIS.exe. Все папки должны оставаться вместе. Пользовательские данные находятся в `%LOCALAPPDATA%\AEGIS`, а не рядом с EXE. Portable использует тот же профиль.

Добавьте контакт по нику, сверьте его отпечаток другим каналом; оба участника добавляют друг друга. В новом письме выберите контакт, задайте пароль письма, отдельный код FF1 и TTL. Можно добавить несколько обычных файлов любых типов; общий предел по умолчанию 16 MiB. Лимиты администратора сервера могут быть ниже: protocol 1 не сообщает клиенту свою конфигурацию. Менять сервер для обновления клиента не нужно.

В открытом письме введите пароль письма и код. Код меняет текст при вводе. «Скачать вложения» создаёт один AES-256 ZIP. Пароль ZIP — **пароль этого письма**, а не код FF1 или пароль аккаунта. Имя существующего файла не перезаписывается. Архив сохраняется явно и не запускается автоматически. После закрытия письма его пароль удаляется из состояния view.

Резервная копия идентичности: Настройки → Экспорт резервной копии идентичности. Для нового backup используется пароль аккаунта на момент экспорта. Он содержит зашифрованную идентичность и контакты, без истории. Полные автоматические копии перед обновлением находятся в `backups\pre-1.0.0-*`. Они сохраняют старый пароль старого vault.

Tor state постоянно находится в `%LOCALAPPDATA%\AEGIS\tor\state`, журнал — `logs\connection.log`. Последний успешный режим Tor запоминается; зависшее соединение переключается на другой режим без прямого подключения к relay. В один момент работает один собственный Tor.

Входящие порты и правила Windows Firewall менять не нужно. SOCKS/Control/P2P слушают только localhost. Defender не отключается; Setup/EXE не имеют коммерческой подписи, поэтому SmartScreen может показать предупреждение. Программа не обходит его.

Реальное обновление на чистой Windows 11 и Windows DPI ещё требует приёмки: в доступной среде Windows отсутствует. Проведённые проверки и границы результата перечислены в TEST-REPORT-1.0.0.md.

## Новые настройки 1.0.0

«Запомнить вход» сохраняет случайный device secret через DPAPI CurrentUser и зашифрованный локальный resume envelope на 7 суток, без пароля аккаунта/письма/FF1. «Завершить сохранённую сессию» удаляет её. Серверный token живёт только 12 часов и сбрасывается при reboot relay; после этого нажмите «Войти в сеть» и введите пароль аккаунта. Не обещается семидневная беспарольная серверная авторизация.

Настройки → Профиль: локальный PNG/JPEG/WebP аватар; контакту можно назначить аватар в «Контакты». Файл до 4 MiB, dimensions до 4096, результат 256×256 PNG без исходных metadata и внешних URL. Аватары зашифрованы в локальном vault и автоматически на relay не отправляются.

Внешний вид: пять пресетов, масштаб 80–125%, плотность списка, sidebar, размер аватаров, preview справа/снизу/выключен, тема/дата. Свой пресет можно сохранить, переименовать, удалить, экспортировать и импортировать JSON без секретов.

Обновления: stable/beta, ручная проверка, automatic check/download, установка по действию пользователя или при закрытии. Всё через собственный Tor, exact Ed25519 bytes проверяются до JSON; затем URL, версия/high-water, размер, SHA-256 и package sanity. AEGIS-Updater.exe копирует helper runtime за пределы старой установки, ожидает конкретный старый PID, заменяет binaries и ждёт startup confirmation; при отказе возвращает старую копию. Адрес установки — %LOCALAPPDATA%\Programs\AEGIS. После первого автоматического обновления portable запускайте AEGIS.exe из этого постоянного каталога; прежняя распакованная папка сама не удаляется.

Подписанные release notes открываются внутри приложения. «Системные» письма об обновлениях локальные, имеют метку ⚙ АЕГИС и не отправляются через relay. Неподписанный/подменённый manifest не даёт ни установки, ни доверенного системного письма. Пока stable канал не опубликован и не подписан владельцем, его проверка может завершаться ошибкой; обычные письма от этого не блокируются.
